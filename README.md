# Echem Plotter

电化学论文曲线图生成器 ／ 電気化学 論文用グラフ作成ツール

A small web tool that turns electrochemistry data (CV / CA / CP) into publication-style figures.

[中文](#中文) ｜ [日本語](#日本語)

## 中文

### 功能

- 支持 CV 循环伏安、CA 计时电流（恒电位）、CP 计时电位（恒电流）
- 读取仪器导出的 txt、CSV、xlsx 文件，可同时上传多个文件叠加显示
- 参比电极换算（Ag/AgCl、SCE、Hg/HgO → RHE）、电流密度归一化，也可以选择不标注参比电极
- 坏点剔除：Hampel 自动检测、按 x 范围、按行号
- 曲线平滑：Savitzky–Golay、移动平均、高斯滤波
- 曲线拟合：线性、多项式、指数衰减、Cottrell，给出参数、标准误差和 R²
- 双 y 轴；曲线、y 轴、拟合线的颜色可以分别设置
- 可调整坐标轴范围、主刻度间隔，以及四边刻度线和刻度数字的显示
- 按期刊栏宽（85 / 120 / 175 mm）出图，导出 PDF、SVG、PNG、TIFF
- 界面支持中文和日文；图中英文使用 Times New Roman，日文使用明朝体
- CV 峰分析（Epa、Epc、ΔEp、E1/2、ipa/ipc），可把峰位标注在图上
- 交互查看：鼠标悬停显示坐标和数据行号，支持十字准线、缩放和平移；处理后的数据可下载为 CSV
- AI 分析（可选，需要自己的 Anthropic API 密钥）

### 在自己电脑上运行

1. 安装 Python 3.10 或更高版本
2. 在本文件夹打开命令行，安装依赖：

   ```
   pip install -r requirements.txt
   ```

3. 启动：

   ```
   streamlit run echem_plotter.py
   ```

浏览器会自动打开页面；没有自动打开的话，访问 `http://localhost:8501`。

### 使用步骤

1. 在左侧选择曲线类型
2. 上传数据文件（没有数据时，可以先勾选"使用示例数据"试用）
3. 选择 x、y 列，设置电流单位、电极面积、参比电极
4. 按需要剔除坏点、平滑、拟合
5. 调整图的尺寸、坐标轴范围、刻度和颜色
6. 在页面下方的"输出图片"里选择格式和分辨率，点击下载

### 交互查看和数据表

结果区域上方有三个标签页：

- **静态预览**：和最终导出的图一致，导出以它为准
- **交互查看**：鼠标放在曲线上会显示坐标和数据的行号，行号可以直接填进"按行号剔除"。滚轮缩放，拖动平移，双击还原
- **处理后的数据**：剔除坏点、平滑、单位换算之后的数据，可以下载为 CSV，导入 Origin 或 Excel

### 坐标轴标签里的上下角标

在"坐标轴标签"的输入框里，用 `$` 括住要变角标的部分，`^` 表示上标，`_` 表示下标，多个字符用 `{}` 括起来。

| 想要的效果 | 输入 |
|---|---|
| cm⁻² | `cm$^{-2}$` |
| H₂O₂ | `H$_2$O$_2$` |
| E 加下标 pa | `$E_{pa}$` |
| µA | `$\mu$A` |

`$`、`^`、`_`、`{}` 都要用英文半角符号，`$` 要成对出现。标签里含汉字时，角标会自动换成 Unicode 字符，此时大写字母的下标不支持。

### AI 分析（可选）

页面最下面的"AI 分析"会把**处理后的数据摘要**（峰位、拟合参数、统计量，不是原始数据文件）发给 Claude，让它帮你解读。

1. 在侧边栏的"AI 分析"里填入你自己的 Anthropic API 密钥，可以补充实验背景、扫速和想问的问题
2. 点"生成 AI 分析"之前，可以展开"查看将发送给 AI 的内容"，确认具体发送了什么
3. 密钥只保存在本次使用的内存里，不会写入文件。**不要把密钥写进代码，也不要上传到 GitHub**

注意：

- AI 的解读可能有误，只能作参考，请对照原始数据和文献自行核对
- 发送的内容会经过 Anthropic 的服务器，未发表的数据请先想清楚是否介意
- 调用 API 会产生费用，由密钥的所有者承担。如果你在服务器上设置了 `ANTHROPIC_API_KEY`（环境变量或 Streamlit 的 secrets），所有使用这个网址的人在没填自己密钥时都会用你的额度，公开部署时不建议这样设置
- 模型名在侧边栏里可以修改；如果提示模型不存在，请到 Anthropic 官方文档的模型列表里查当前可用的名称

### 注意事项

- **数据格式**：读取功能只用 CHI 仪器的导出格式验证过，Gamry、BioLogic 等其他仪器的格式还没有测试。如果表头出现乱码，在侧边栏的"文件编码"里手动选择 GBK 或 Shift-JIS。
- **拟合**：拟合使用的是剔除坏点后、未平滑的原始数据。
- **字体**：本地运行时，图中的字体取决于电脑上安装的字体（Times New Roman、日文明朝体）。没有安装时会自动使用替代字体，外观可能略有不同。
- **隐私**：在自己电脑上运行时，数据只在本机处理。部署到云端后，上传的数据会在服务器上处理，尚未发表的数据请谨慎使用。

## 日本語

### 機能

- CV（サイクリックボルタンメトリー）、CA（定電位）、CP（定電流）に対応
- 装置から出力した txt、CSV、xlsx を読み込み、複数ファイルの重ね描きも可能
- 参照電極の換算（Ag/AgCl、SCE、Hg/HgO → RHE）、電流密度への規格化。参照電極を記載しない選択もできます
- 外れ値の除去：Hampel による自動検出、x 範囲指定、行番号指定
- 平滑化：Savitzky–Golay、移動平均、ガウシアンフィルタ
- フィッティング：直線、多項式、指数減衰、Cottrell（パラメータ、標準誤差、R² を表示）
- 二軸グラフ。曲線、y 軸、フィット線の色を個別に設定できます
- 軸の範囲、主目盛りの間隔、四辺の目盛り線と目盛りの数値の表示を調整可能
- 論文の段幅（85 / 120 / 175 mm）に合わせて出力し、PDF、SVG、PNG、TIFF で保存
- 画面は中国語と日本語に対応。図中の英字は Times New Roman、日本語は明朝体
- CV ピーク解析（Epa、Epc、ΔEp、E1/2、ipa/ipc）。ピーク位置を図に表示することもできます
- インタラクティブ表示：カーソルを重ねると座標とデータの行番号を表示。十字線、拡大縮小、移動に対応。処理後のデータは CSV でダウンロード可能
- AI 分析（任意。自分の Anthropic API キーが必要）

### 自分のパソコンで実行する

1. Python 3.10 以上をインストール
2. このフォルダでコマンドラインを開き、依存パッケージをインストール：

   ```
   pip install -r requirements.txt
   ```

3. 起動：

   ```
   streamlit run echem_plotter.py
   ```

ブラウザが自動で開きます。開かない場合は `http://localhost:8501` にアクセスしてください。

### 使い方

1. 左側で測定の種類を選ぶ
2. データファイルをアップロード（データがないときは「サンプルデータを使う」で試せます）
3. x 列・y 列を選び、電流の単位、電極面積、参照電極を設定
4. 必要に応じて外れ値の除去、平滑化、フィッティング
5. 図のサイズ、軸の範囲、目盛り、色を調整
6. ページ下部の「画像を出力」で形式と解像度を選んでダウンロード

### インタラクティブ表示とデータ表

結果エリアの上に 3 つのタブがあります。

- **静的プレビュー**：最終的に出力される図と同じ内容です。出力はこれが基準になります
- **インタラクティブ表示**：カーソルを曲線に重ねると座標とデータの行番号が表示されます。行番号は「行番号で除外」にそのまま入力できます。ホイールで拡大縮小、ドラッグで移動、ダブルクリックで元に戻ります
- **処理後のデータ**：外れ値の除去、平滑化、単位換算をした後のデータです。CSV でダウンロードして Origin や Excel に取り込めます

### 軸ラベルの上付き・下付き文字

「軸ラベル」の入力欄で、添字にしたい部分を `$` で囲みます。`^` が上付き、`_` が下付きで、複数文字のときは `{}` で囲みます。

| 表示したいもの | 入力 |
|---|---|
| cm⁻² | `cm$^{-2}$` |
| H₂O₂ | `H$_2$O$_2$` |
| E に下付き pa | `$E_{pa}$` |
| µA | `$\mu$A` |

`$`、`^`、`_`、`{}` は半角で入力し、`$` は必ず対にします。漢字を含むラベルでは添字が Unicode 文字に自動変換されるため、大文字の下付きは使えません。

### AI 分析（任意）

ページ下部の「AI 分析」は、**処理後のデータの要約**（ピーク位置、フィットのパラメータ、統計量。元のデータファイルではありません）を Claude に送り、解釈してもらう機能です。

1. サイドバーの「AI 分析」に自分の Anthropic API キーを入力します。実験の背景、掃引速度、質問も追加できます
2. 「AI 分析を実行」を押す前に、「AI に送る内容を確認する」を開くと、実際に何を送るかを確認できます
3. キーは今回の利用中だけメモリ上に保持され、ファイルには書き込まれません。**キーをコードに書いたり、GitHub にアップロードしたりしないでください**

注意：

- AI の解釈は誤っていることがあります。参考程度にとどめ、元のデータや文献と照らして確認してください
- 送信内容は Anthropic のサーバーを経由します。未発表のデータの扱いにはご注意ください
- API の利用には料金がかかり、キーの持ち主が負担します。サーバーに `ANTHROPIC_API_KEY`（環境変数または Streamlit の secrets）を設定すると、自分のキーを入力していない利用者全員があなたの利用枠を使うことになるため、公開デプロイではおすすめしません
- モデル名はサイドバーで変更できます。モデルが存在しないと表示された場合は、Anthropic 公式ドキュメントのモデル一覧で現在使える名前を確認してください

### 注意事項

- **データ形式**：読み込みは CHI 装置の出力形式でのみ動作を確認しています。Gamry、BioLogic など他の装置の形式は未確認です。ヘッダーが文字化けする場合は、サイドバーの「文字コード」で GBK または Shift-JIS を手動で選んでください。
- **フィッティング**：外れ値を除いた、平滑化前のデータを使います。
- **フォント**：自分のパソコンで実行する場合、図のフォントはインストールされているフォント（Times New Roman、日本語の明朝体）によって決まります。ない場合は代替フォントが使われ、見た目が少し変わることがあります。
- **プライバシー**：自分のパソコンで実行する場合、データはそのパソコンの中だけで処理されます。クラウドに公開した場合、アップロードしたデータはサーバー上で処理されるため、未発表のデータの扱いにはご注意ください。
