# Echem Plotter：電気化学 論文用グラフ作成ツール

[中文版 README](README.md)

Streamlit で作った小さなツールです。電気化学測定装置から書き出したデータファイルを読み込むだけで、論文向けのグラフを作成できます。電荷量・比容量、フィット、CV のピーク位置などの解析も行えます。画面の言語は中国語と日本語を切り替えられます。

対応している測定の種類は次の 3 つです。

| 種類 | 内容 | 既定の横軸 / 縦軸 |
|---|---|---|
| CV | サイクリックボルタンメトリー | 電位 / 電流 |
| CA | クロノアンペロメトリー（定電位） | 時間 / 電流 |
| CP | クロノポテンショメトリー（定電流） | 時間 / 電位 |

## インストールと起動

Python 3.9 以上が必要です（開発とテストは Python 3.12 で行っています）。

```
pip install streamlit pandas numpy scipy matplotlib plotly openpyxl google-genai
streamlit run echem_plotter3.py
```

ブラウザが自動で開き、`http://localhost:8501` が表示されます。`streamlit` コマンドが見つからない場合は、`python -m streamlit run echem_plotter3.py` を使ってください。

`plotly` は「インタラクティブ表示」、`openpyxl` は `.xlsx` の読み込み、`google-genai` は AI 分析に使います。この 3 つをインストールしなくても、ほかの機能は使えます。

## 基本の使い方

1. サイドバーで測定の種類（CV / CA / CP）を選びます。
2. 測定装置から書き出した `txt` / `csv` / `xlsx` をアップロードします。複数ファイルを選ぶと重ね描きできます。ファイルがないときは、「ファイル未選択時はサンプルデータを使用」にチェックを入れると試せます。
3. 「データ」で x・y の列と単位を確認し、必要に応じて他の設定を調整します。
4. ページ下部で形式と解像度を選び、画像をダウンロードします。

## データファイルの読み込み

- 区切り文字（タブ・カンマ・セミコロン・空白）と小数点（ピリオドまたはカンマ）を自動で判定します。
- ヘッダーを自動で見つけます。Gamry のように「名称の行 + 単位の行」がある形式にも対応しています。空のセルは NaN として扱い、ファイル冒頭の数字だけの行をデータと間違えることはありません。複数のデータブロックは連結します。
- データ行に文字の列（「ステップ種別」など）が混ざっていても読み込めます。文字の列は破棄されます。
- `.xlsx` の文字列の時間（`0:00:30`）や日時は秒に変換します。シートが複数ある場合は、データが最も多いシートを使います。
- 文字化けするときは、「文字コード」で UTF-8・GBK・Shift-JIS を手動で選んでください。
- 列数が合わずにスキップした行があると、画面に表示されます。

### 列と単位の自動認識

列名から、各列が時間・電位/電圧・電流・電荷量/容量・番号のどれかを判断し、x・y 列の既定値を決めます。中国語・英語・日本語の表記に対応しており、`Potential/V`、`Ewe/V`、`<I>/mA`、`Vf`、`Im`、`電圧(V)`、`電流(mA)`、`測定時間` などを認識します。名前に「ステップ」が付く時間列や、「control」のような設定値の列は、候補の優先順位が下がります。

単位も列名から読み取ります。時間は s / ms / min / h、電流は A / mA / µA / nA / pA、電位は V / mV です。列名に単位が書かれていない場合は s / A / V として扱います。「元データの時間単位」「元データの電流単位」「元データの電位単位」は既定で「自動」になっており、手動で指定することもできます。

複数のファイルを選んだ場合は、ファイルごとに列を探します。列の順番が違っていても問題ありません。

選んだ列が測定の種類に合っていないとき（たとえば CA で y に電位を選んだ場合）は、サイドバーに注意が表示されます。

## データ処理

- **外れ値の除外**：Hampel による自動検出、x の範囲で除外、行番号で除外。
- **座標の詰め方**：点を除外した後の座標を、「すべて詰める」「先頭だけ詰める」「詰めない」から選べます。詰める処理は時間軸にだけ働き、CV の電位は変更されません。
- **平滑化**：Savitzky–Golay、移動平均、ガウシアンフィルタ。元データを薄い色で重ねて表示することもできます。
- **フィット**：CV は直線・多項式。CA はこれに加えて Cottrell・指数減衰、CP は指数も選べます。フィットには平滑化前の元データを使います。
- **CV のピーク解析**：Epa、ipa、Epc、ipc、ΔEp、E1/2、ipa/|ipc| を図に表示し、表にも出します。ベースライン補正は行いません。

## 単位と参照電極

- 時間の表示単位：s / ms / min / h。
- 出力する電流の単位と、電極面積による規格化（電流密度）。
- 参照電極：SHE、Ag/AgCl (sat. KCl)、SCE、Hg/HgO (1 M NaOH)、Hg/Hg₂SO₄。名称と SHE 基準の電位を指定するカスタム参照電極も使えます。
- SHE または RHE への換算ができます（RHE には溶液の pH が必要です）。任意のオフセットを加えることもできます。

内蔵している参照電極の電位は一般的な参考値です。実際の値は電極の内部液や温度によって変わります。定量的な換算を行う前に、お使いの電極の公称値と照らし合わせて確認し、必要なら「カスタム参照電極」で値を入力してください。

## 電荷量と比容量

「電荷量グラフを作成」または「比容量グラフを作成」にチェックを入れると、関連する設定が表示されます。

- 電荷量 Q は、電流を時間で台形積分して求めます。1 mAh = 3.6 C です。
- CA は y 列の電流を使います。CV は y 列の電流を使い、時間はファイル内の時間列を優先し、なければ掃引速度と電位変化から推定します。CP の電流は電流列から取得するか、定電流（mA）を手入力できます。
- 既定では、電流の正負（CV は掃引方向）で自動的に区間に分け、各区間を 0 から積算します。そのため、充電と放電の曲線は分かれて描かれます。「区切らない」を選ぶこともできます。
- 積分には残した点だけを使います。除外した点と NaN は使いません。時間が戻る所では区切るので、負の電荷量にはなりません。各区間の先頭の 1 サンプル間隔は含まれません。
- 活物質の質量（mg / g / µg）を入力すると、比容量（mAh g⁻¹）が得られます。0 の場合は mAh のまま表示します。活物質とは、反応に実際に関わる材料のことで、導電助剤・バインダー・集電体は含みません。
- ページには、区間ごとのまとめの表（方向・点数・時間・Q・容量）が表示されます。

## グラフの設定

主図・電荷量グラフ・比容量グラフには、それぞれ独立した設定があります。

- グラフのタイトル、軸ラベル（`$E_{pa}$` のような LaTeX の数式に対応）。
- x・y の範囲と主目盛りの間隔（空欄なら自動）。
- 各軸の色：黒 / 曲線の色に合わせる / カスタム。
- 曲線の色、点または線での表示。電荷量グラフと比容量グラフの曲線の色は、既定では主図に合わせます。
- 凡例：表示 / 非表示、位置、位置の手動指定、列数、枠線、曲線ごとのカスタム名。
- 目盛り線、目盛りの数値、補助目盛り、目盛りの向き。
- 図の幅（85 / 120 / 175 mm、1 段組・1.5 段組・2 段組）、高さ、文字サイズ。

主図では、**右側の第 2 y 軸**と**上側の第 2 x 軸**も使えます。上側の x 軸は、選んだ列を横軸にして、左 y 軸のデータをもう一本描きます。色と凡例名は個別に設定できます。

### 基準線

主図・電荷量グラフ・比容量グラフのそれぞれに、基準線を最大 10 本まで追加できます。水平線または垂直線、位置（データ座標）、色を自由に決められ、線の種類は破線・点線・一点鎖線・実線から選べます。二軸のときは、各線がどの軸に対応するかも指定できます。

### テキストボックス

数式に対応したテキストボックス / 注釈を最大 10 個まで追加できます。データ座標または相対座標、文字サイズ、色、回転角、枠のスタイルを選べ、どのグラフに表示するかも指定できます。

## 出力

- 形式：PNG、PDF、SVG、TIFF。解像度は 300 / 600 / 1200 dpi。ファイル名の接頭辞も設定できます。
- PDF と SVG の文字は編集可能なままなので、Illustrator や Inkscape で続けて修正できます。
- 「処理後のデータ」タブから CSV をダウンロードでき、そのまま Origin に読み込めます。
- 「インタラクティブ表示」タブでは、カーソルを合わせて数値を読み取ったり、十字カーソルを表示したりできます。

## AI 分析（任意）

処理後のデータの要約を Google Gemini に送り、文章の分析を生成します。結果は参考情報なので、必ずご自身で確認してください。

API キーは 3 つの方法で指定できます。サイドバーに直接入力する方法、`.streamlit/secrets.toml` に `GEMINI_API_KEY = "..."` と書く方法、環境変数 `GEMINI_API_KEY` を設定する方法です。サイドバーに入力したキーはメモリ上にのみ保持されます。

## 既知の制限

- 列の認識は列名に頼っています。時間・電位・電流などの手がかりが名前にまったくない列は、位置による選択に戻るので、手動で確認してください。
- 元データの時間は、既定では秒として扱います。時間が min や h なのに列名に単位がない場合は、「元データの時間単位」を手動で指定してください。
- 幅 85 mm の図で右 y 軸と上側 x 軸を同時に使い、軸ラベルが長いと、レイアウトが窮屈になることがあります。その場合は 120 mm か 175 mm にしてください。
- CV の「電荷量」は掃引方向ごとの区間で表示します。「総量の半分」が必要な場合は、アノード側とカソード側の区間の平均を自分で求めてください。
